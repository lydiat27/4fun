# Keychain Studio

A tiny static site for building your own bag charm, piece by piece:

1. **Ring** – spring ring, split ring, carabiner, lobster clasp or gold hoop
2. **String** – cord, ribbon or ball chain, in a few colors, with one to three strands
3. **Charms** – tap a strand, then tap a charm or bead to thread it on. Drag charms to slide them along (or onto another strand), tap one to take it off.
4. **Done** – watch it swing and save it as a PNG.

No build step. Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```
